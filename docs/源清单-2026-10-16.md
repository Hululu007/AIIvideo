## 怎么加

1—8 是苹果CMS，**把接口地址直接贴进设置页**就行。App 探测完自动生成 `paths` / `fields` /
`ui`，不用手写配置。`categories` 的 slug 就是 `type_id`，`ui.tabs` 按源自己的分类树生成。

9—10 是配置文件的 https 地址，同样贴进设置页。

## 播放域和接口域是分开的

八条苹果CMS 的接口全在 Cloudflare 上（`104.21.x.x` / `172.67.x.x`），播放域一个都不是。
接口给的是**完整地址**，所以不用管这个区别——但换域名的时候接口和播放域会各自换，死法不同：

- 接口域挂 → 列表都拉不出来，一眼能看见
- 播放域挂 → 列表正常、点开播不了，**看不出来**

第二种才是常见死法。

## 源身份

同一套判定规则，各自归一成一个 key：

```
agedm  → hgsrc:agedm|https://api.agedm.io/v2/detail/
黄果   → hgsrc:rest|https://cab3f.nt17g20k.cc/api/videos/
苹果CMS → hgsrc:cms|<接口地址>
```

观看历史按这个 key 隔离，换源之后属于别的源的条目不显示。
