## 二、我们的 bug（要改 App）

**① reconcile 对没有 origin 的源硬拼相对路径。** 56 条 / 5 台，2.0.21 / 2.0.23 / 2.0.26

```

```

`app/src/main/assets/app.js:1320`：

```js

```

这条给的是纯路径，`SiteProfile` 要拿 `origin` 拼才成地址。而 2026-10-16 起允许
