# 值班台 —— 后台重做方案

方案，不是成品说明。P0 落地后回来补一页「实际长这样」，并删掉本句。
现状截图留在 `work/shots/admin-before/`。

## 0. 先核账

登录逐页点过（Chromium 1440 宽），数字对着 `/srv/cfg` 和容器里的库存核：

| 项 | 数 |
|---|---|
| 后台能编辑的文件 | `/srv/cfg` 顶层 **6** 个 json |
| 真正在用的源 | `/srv/cfg/spiders` 下 **13** 份配置 + 13 份 js（目录共 36 个文件，其余是 `.bak-*`） |
| App 用户 | **189**，近 7 天新增 188 |
| 审计 | **20** 条，最近一次登录当天 04:51 |

后台管的那一层，已经不是内容所在的那一层了。这是"粗糙"的第一层：**结构停在两代之前**。

第二层才是长的样子：近黑底 `#0e1114` + 天蓝主色 `#3d9bff` + 一堆同半径圆角卡片 + 全大写小标签。这套是任何后台的默认长相，跟"十八个会自己坏掉的爬虫"这件事没有任何关系。

## 1. 主体

- 使用者：一个人。深夜改 JSON，白天看有谁注册了。
- 手头的活：源还能不能跑 → 换配置 → 发布到清单 → 出事了回滚。
- 真实对象：13 个站点级爬虫，每个都有自己的脾气 —— 需代理、Cloudflare 盾后、封面是 AES 密文、播放要跑站点 wasm。这些话现在就写在 `market-spider.json` 的 `desc` 里。
- 界面的任务：让人一眼看出哪个源该动手，以及刚才那一改到底改了什么。

## 2. 方向：值班台

做成**一块搪瓷仪表板**，不做成网站。

三条硬规则：

1. **颜色只报状态。** 屏幕上任何一块有颜色的东西都在说系统的事：就绪、待验、坏了、盾后。品牌色不做强调色 —— 主按钮是墨黑，链接是墨黑加下划线。想强调某处，用位置和字重，不用颜色。
2. **线分台，标签进页边。** 不用卡片堆内容。每块内容是一"台"，台与台之间一条 1px 墨线，台的标题放在左边 132px 的页边栏里，和内容顶对齐，像图纸的边注。
3. **值等宽，右对齐。** 时间、大小、URL、行号、计数全部等宽 + `tabular-nums`。看十个时间不用左右扫。

唯一的"重头戏"是**灯带**：每页顶部一条，13 个灯，一个源一个。看见它就看见了整个农场。其余一律安静。

## 3. 令牌

### 色

| 名字 | 日间 | 夜间 | 用在哪 |
|---|---|---|---|
| `ground` | `#E6E6E1` | `#141614` | 页面底 |
| `face` | `#F7F7F3` | `#1B1E1A` | 侧栏、输入框、表头 |
| `ink` | `#17181A` | `#E7E7E0` | 正文、强调线、主按钮 |
| `ink-2` | `#55595C` | `#A0A49C` | 次要信息、页边标签 |
| `rule` | `#C6C7C0` | `#33362F` | 分隔线 |
| `live` | `#15683B` | `#5FBF86` | 就绪 |
| `warn` | `#8A5800` | `#D9A03C` | 待验 / 需代理 |
| `dead` | `#A62B1F` | `#E3776A` | 配置坏 / 缺 js |
| `shield` | `#2A4C86` | `#8FAEE0` | 整站盾后 |

四个信号色是语义，不是调色板：任一时刻屏幕上出现的彩色像素，都在回答"这个源怎么了"。日间默认，夜间跟 `prefers-color-scheme`，侧栏底部有手动开关，存 localStorage。

### 字

| 角色 | 字体 | 规格 |
|---|---|---|
| 界面正文 | PingFang SC → Noto Sans SC → system-ui | 13.5px / 1.7 |
| 值（url、json、时间、字节、行号、计数） | 自托管 IBM Plex Mono 400/500（latin 子集 woff2，两档共约 40KB），取不到回落 `ui-monospace` | 12.5px / 1.5，`tabular-nums` |
| 页标题 | 界面字体 | 21px / 600，`-0.01em` |
| 台标题（页边） | 界面字体 | 12px / 500，`ink-2`，句首大写 |
| 表头 | 界面字体 | 11.5px / 500，`ink-2`，**不转大写、不加字距** |
| 大数字（只有总览一个） | Plex Mono | 34px / 600，`tabular-nums` |

说明文字行宽 ≤ 64 汉字。中文不要小于 12px。

### 网格与密度

- 侧栏 216px 固定。主区 = 页边 132px + 内容 `1fr`，内容最大 1180px。
- 表格行高 **34px**（现在是 73）。只有行分隔线，不套盒子。数字列右对齐。
- 台间距 32px，台界一条 1px `ink` 线。圆角 0；输入框和按钮 2px。焦点环 2px `ink`，偏移 2px。无阴影、无渐变。
- 断点：1080 收成两列；860 侧栏变顶栏；560 宽表格转成「标签 / 值」堆叠，不横向滚动。

- **总览**：灯带 + 四组计数 + 「需要你动手」（配置坏的、缺 js 的、备份堆着的、只读的）+ 最近 12 条动作。现在那三个等高大卡片，撑到 800px 高、里面 200px 是空的，删掉。
- **源**：一行一个源。列＝灯／名字／站点 host／适配器／大小／改于／动作。上面是 `spiders/` 的 13 个，下面是顶层那 6 个老配置（明确标"老一代"，因为 `agedm.json`、`huangguo.json` 在两边各有一份）。搜索框 + 「只看要动手的」。
- **源编辑**：左边编辑器（行号栏、等宽、不折行、水平滚动），右边"检查"栏：结构校验结果、条目数、指向的 json/js 是否存在、备份时间线、本次改动 +N/−M 行。动作条 sticky 在底部：`保存并生效（留备份）`／`格式化`／`放弃改动`，⌘S 同保存。
- **清单**：两张表并排。`market-spider.json`（在用）在上，`market.json`（旧版 REST，客户端还认）在下，各自勾选 + 就地改描述 + 显示"指向的文件 HTTP 200 / 404"。写之前按钮就写清"将写入 N 条"。
- **用户**：189 行、30 一行、行高 34，一屏 20 行。重置口令与删除改成行内展开（原生 `<dialog>`，显示用户名让人确认），不用 `prompt()`。
- **审计**：紧凑表，动作做成小标签，目标文件名等宽。
- **账号**：左"当前登录"，右改口令。两栏，不要一竖列三个输入框。
- **登录**：一块搪瓷牌。标签在左、输入在右，单列对齐。底下压一行 `149.104.21.177 · 2026-10-23`。没有别的装饰。

## 5. 五个页面级决定

1. **灯带**是唯一彩色重物，每页都在，位置固定 —— 它是这套界面的记忆点。
2. **页边标签**承担分节，取代 `<h2>` + 分割线。扫视时眼睛只需要看一列。
3. **等宽值**让"哪份更新"这种问题不用读，直接比。
4. **破坏性动作就地展开**：删除、回滚、重置口令都在原地给确认块，写明对象和后果，不用浏览器 `prompt/confirm`。
5. **错误说人话并给出下一步**：`第 14 行第 3 列少了逗号 —— 补上再保存，或从下面 10-21 03:18 那版回滚`。现有实现是 `alert('JSON 语法错误：' + error.message)`。

## 6. 自我复核：砍掉了什么

初稿是深色 + 一个亮青主色，跟现在这版只差色号 —— 那等于没做。逐条对照通用默认，砍掉：

| 砍掉 | 为什么 |
|---|---|
| 近黑底 + 单一亮主色 | 任何后台的默认长相；这里也没有"品牌"要表达 |
| 三张等高大圆角卡片 | 卡片本身不携带信息，还把页面撑出大片空白；换成"需要你动手"的清单 |
| 全大写小标签、字距加宽、`01/02/03` 编号 | 这里没有顺序，也不是标题系统；编号只是装饰 |
| 每个链接尾巴上的 `→` | 箭头不传递信息，位置已经说明可点 |
| 卡片阴影、渐变洗底 | 面板靠线分层，不靠光影 |
| 中英混排的空格排版 | 用等宽字体承担"这是机器值"的区分，不靠字距 |

保留的冒险只有一条：整块界面接近无彩，颜色只留给状态。这在运维台里是对的（颜色必须是数据），在别的地方会显得冷淡，所以只在这里用。

## 7. 顺手要修的功能缺口

这不是审美问题，是"后台现在做不了它的活"：

1. **13 个 spider 源后台看不见。** 只能编辑 `/srv/cfg` 顶层的 6 个 json。
2. **市场页写的是退役清单。** 它读写的 `market.json` 是旧版 REST 清单；在用的 `market-spider.json` 只能 scp 改。更糟的是它把 `market-spider.json`、`sources.json` 自己列成"源"供勾选，勾上就会自我引用。
3. **导航高亮用子串匹配。** 打开 `/sources/market-spider.json/edit`，"源文件"和"市场清单"两个都点亮（因为文件名里含 `market`）。
4. **编辑器没有行号、高亮、diff**，保存按钮在折叠线下，错误走 `alert`。
5. **用户页一行 73px**，一屏 7 个用户；操作按钮溢出表格右边界（截图里能看到越界）。

## 8. 卫生问题（跟改版一起收）

- `/srv/cfg` 是 `file_server browse` 的根：**`Caddyfile` 能被直接下载**（里面是 basicauth 的 bcrypt），`spiders/*.bak-*` 备份、整个 `spiders/` 目录都可列可读。
- 备份现在双份：后台写到 `/data/backups`，手工 scp/编辑留下的 `.bak-*` 躺在公开目录里。统一收到 `/data/backups`，Caddy 加一条 `*.bak-*` 404。
- `deploy.sh` 注释说改模板/静态文件 `--no-build` 够用。实际 Dockerfile 是 `COPY app ./app`，不重建镜像等于没发。注释改掉，或者给开发机加一份 bind mount 的 override。

## 9. 落地顺序

**P0 换皮 + 重排**（只动 `templates/`、`static/`、`main.py` 的展示层）
重写 `app.css`（一文件，令牌 + 组件，约 700 行）、8 个模板、新增 `static/app.js`（约 120 行：夜间开关、⌘S、格式化带行内报错、行内确认框、diff 行数）、`static/fonts/`。后端口径不变。

**P1 让它管到真东西**
`/spiders` 段（读 json + js，js 只读预览）、清单改管 `market-spider.json`、服务端"验证"按钮（拉配置和 js，结果存 sqlite `checks` 表，灯带从此用真数据）、导航按精确路由高亮。

**P2 卫生**
公开目录停服 `.bak-*`、`Caddyfile` 挪出站点根、备份目录统一。

- 本机跑 `uvicorn`，`CFG_DIR` 指向 `/srv/cfg` 的**只读副本**，`MOUNT_PATH=` 空。改到满意再发。
- 每页 1440 / 768 / 390 三档截图，逐页对 `work/shots/admin-before/`。

- 对比度：正文 ≥ 7:1，次要 ≥ 4.6:1，信号色作小字时 ≥ 4.5:1。

## 11. 不做

- 不加前端框架、不引入构建步骤。服务器上没有 node，也不该为了这块面板装一个。
- 不做多用户 / 权限分级。一个人用，加角色只是给自己加门。
- 不做代登录、不展示用户内容。后台只需要处置账号，不需要拿会话。
- 不在这一轮改 `/srv/cfg` 的文件组织（顶层 6 个 json 的清理是另一件事）。

## 和方案不一样的地方

落的时候发现的，改了方案：

1. **手机端不重排成卡片。** 原计划 560px 以下把表格转成「标签 / 值」堆叠。真做出来发现
   四五个数字脱离表头就没意义了（"27"是哪一列？），而且实现要按表写死。改成整表横向滚动
   （`.scrollx`），表头跟着走，比堆叠可读。
2. **总览不摆全量源表。** 方案里有一张「源文件速览」，做出来和 `/sources` 重复，删了，
   换成「需要你动手」+「数量」两张短表。
3. **对话框一行一个改成一个轮流用。** 14 个源 × 一份 dialog，页面白背 10KB 死代码。改成
   `[data-dialog]` 按钮自带 action 和目标名，一个弹层填一次。用户页同理（30×2 个压成 2 个）。
4. **危险动作用了填色。** 方案说"主按钮是墨黑"，但删除确认如果和「算了」长得一样重，
   眼睛没有刹车。全站只有这一个地方填 `--dead`。
5. **编辑器标题用界面字体**，路径挪进 meta —— 等宽字体撑到 21px 太吵。

## 顺手修掉的真 bug

写的过程中撞到的，不修就是给自己埋雷：

| 现象 | 原因 |
|---|---|
| `market-spider.json` 保存时报「缺少 adapter / api / origin」 | 校验按 `name.endswith("market.json")` 判清单 —— 一眼看去对，实际 `market-spider.json` 不以它结尾 |
| `/sources/market-spider.json/edit` 永远 303 | `safe_rel` 里写成了 `directory in filename`，空目录名是任何字符串的子串，恒真 |
| 带中文提示的重定向会 500 | `Location` 头只吃 latin-1，提示词要 `quote()` |
| 本地起服务登录后被弹回 | `auth.require` 把 `/admin/login` 写死了，`MOUNT_PATH` 为空时跳不着 |
| 顶层的 `yhdm.json` 这类 spider 配置存不进去 | 校验要求 `adapter / api / origin` 之一，spider 配置只有 `web.spider` |
