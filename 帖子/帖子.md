# AIIvideo —— 一个自己配源的安卓看片壳子

先说明白这是什么：**AIIvideo 本身不带任何影视内容。** 它是个播放器外壳，内容全部来自你自己填的源——苹果 CMS 接口、动漫站、文件站、KVS 站都行，App 负责识别、抓取、解密、播放。所以你装完第一次打开是空的，必须先给一个源地址才有东西看。

这样做的好处是：源挂了换一个源就行，不用等发新版；坏处是第一次配置得走几步。这个帖子分两半，前半是这次改了什么，后半是照着点一遍就能用的新人指引。

---

## 一、1.0.19 以来修了什么、加了什么

从 1.0.19 到现在是 1.0.26，中间隔了六版。挑有感觉的说。

### 内置播放器（1.0.19）

WebView 解不了 HEVC / H.265、10bit、冷门音频，以前这种片子只能眼睁睁看着黑屏。现在 App 自带 libVLC，解不动的直接丢给本地软解，不用再装 MX Player 或 VLC。

- 设置 → 播放器：播放内核（网页 / 内置 VLC）、解码方式（自动 / 一律软解）、网络缓存（800 / 1500 / 3000ms）、解码失败自动切内置
- 播放页右上角有「内置」按钮，这一集临时想换内核随时点，进度照常写回观看历史
- 只打 arm64-v8a。32 位机器自动退回网页播放器，不会闪退

### 修掉「应用内更新从来没成功过」（1.0.19）

下载地址多拼了一段 tag，落到 404。也就是说 1.0.19 之前，所有人点「下载并安装」都是失败的，只是没人报。现在服务器上那条老路径也做了兼容，装着旧版的人可以直接在 App 里升上来。

### 修掉「已是最新版本」的谎话（1.0.19）

一小时点满 5 次会被限流，以前限流和「真的没新版」显示的是同一句话。现在分开说。

### 更新和节点池不再依赖我自己的服务器（1.0.24）

热更清单、热更包、APK 清单、免费节点池，这四样都是静态文件，以前全挂在一台香港机器上。那台一欠费、一被封、一磁盘满，全世界就收不到更新。现在搬进仓库，客户端走三个候选地址（`gh.dpik.top` → `gh-proxy.com` → `raw.githubusercontent.com`），谁通用谁。

自己的服务器上只剩账号 API 还依赖着，那个是真的需要服务端逻辑。

### 修掉一个让热更新从来没生效过的 bug（1.0.24）

打包时把资源包（zip 字节）直接写进了信封文件 `envelope.json`，而验签又是拿这个文件去解析 JSON。对一堆 zip 字节做 JSON 解析，必然抛异常。

后果不是「热更失败」这么简单：启动时每次走 catch，新版本被标成 blocked，active 被清掉，最后回退到内置界面。表现就是**下载了、提示了「下次启动生效」、重启之后永远是内置版本**，而且一条错误日志都不打。查了很久。

### 热更新换了密钥（1.0.24）

旧私钥本机和服务器上都找不到了，只剩公钥，等于通道已经签不动。换了一对新密钥。**这意味着热更通道只对 1.0.24 及以后生效**——装更早的版本收不到热更包，但也不会出错，验签不过就当没有更新。

### 免费节点池支持热更新了（1.0.24）

以前 `free-nodes.json` 是打进 APK 的，节点死了只能发新版。现在三级回退：本地缓存 → 远端候选 → 内置。设置页多了「节点库：维护于 X · N 条」和「检查更新」。

节点池有准入校验：劫持门户的 HTML、半截文件、「JSON 合法但链接全是核心不支持的协议」，三种都拦得住，校验不过就不写盘，旧缓存原样留着。

### 适配器重构 + 三个新站（1.0.25）

所有站点适配收成一份注册表，加站点只改一处。同时新接了三类站点：文件站 OpenList（asmrgay.com，卡片是目录，伪装成 .jpg/.woff2 的 MPEG-TS 按体积放行）、91porn（901.26702.app，补了站点识别，修了中文搜索一直是 0 结果的问题），以及每日大赛（mrds66）的 UA 被挡、封面 AES 解密、简介带残标签三个毛病。

### 修源市场清单的报错误导（1.0.26）

在设置页贴 `market.json` 这种源清单，本来应该列出可勾选的源；失败时显示的是「认不出这是什么配置」，可实际原因是网络超时。显示的原因和真实原因差着十万八千里，照着它排查必然走错方向。现在拉不下来会直接说清楚是超时、404 还是格式不对。

## 二、新人指引：从装完到能看片

### 第 1 步：第一次打开，先给一个源

装完打开是一片黑，中间弹一个「设置源」面板，就一个输入框要你填地址 —— 因为它真的什么都没有。

在输入框里贴这一行，然后点「获取并应用」：

```
https://149.104.21.177.sslip.io/market.json
```

它是**一份源清单**，不是单个源。贴进去之后 App 不会直接生效，而是把清单里的站点列出来让你挑：

![源清单列表](https://i.mji.rip/2026/10/18/2b12b3274fae3bec9d1e1628a5db74d5.jpeg)

能多选。**第一次先挑不需要代理的**：影视线路 1、影视线路 2、AGE动漫、黄果短剧。这四个直连就能用，先跑通一个再说别的。

注意一个坑：**最后一个勾的才是当前生效的源**，前面勾的只是进了源列表，方便以后切。

### 第 2 步：认识设置页

进「我的」→ 右上角设置，长这样：

![设置页](https://i.mji.rip/2026/10/18/a0576613e133412565c0ac7ed37bc000.jpeg)

上往下：内容源（当前用的是哪个）、源市场（点一下换一个源）、网络代理、播放器、外观、账号、版本、片单（历史 / 收藏）、缓存。

大部分东西不用动。需要动的是「网络代理」和「源市场」这两块。

### 第 3 步：源市场随时加源

设置 → 源市场，把刚才那个清单地址填进去：

![源市场填地址](https://i.mji.rip/2026/10/18/dff7a721b5a8aa40afa4efdec0c93059.jpeg)

点「使用这个市场」，出来的是完整清单：

![源市场列表](https://i.mji.rip/2026/10/18/f4758b49c6396dba6f3ab7a3c69c3fe2.jpeg)

每个源右边一个「添加并使用时」。点一下就会加进源列表并切过去，然后 App 重启。上面写着「使用中」的那个就是当前源。

标着**需代理**的四个——Hanime1（里番）、每日大赛（吃瓜爆料）、ASMR基佬中心（音声 / 文件站）、91porn（KVS 视频）——直连打不开，必须先配代理。看下一段。

### 第 4 步：配代理（这一步最要命）

不配代理，需代理的那几个源全是空白页或者一直转圈，很多人就在这儿放弃了。

我的 → 网络代理，三档：**直连 / 内置核心 / 外部地址**。

- **直连**：什么都不走，只适合上面那四个直连源。
- **内置核心**：App 自己在本机起一个 SOCKS5。你贴一条 `vmess://`、`vless://`、`trojan://`、`ss://` 分享链接就能用，不需要装任何第三方 App。
- **外部地址**：你手机上有 Clash、v2rayNG 之类的，填它的本地地址（例如 `socks5://127.0.0.1:7890`）。

![代理和免费节点](https://i.mji.rip/2026/10/18/c9203fce02179395f8fdae6642e76181.jpeg)

**没有节点也没有机场的**，直接看「免费节点」那一块，点「测速并挑选」，它会一个个试，挑延迟最低的连上。当前这版内置 7 条实测可用的 HTTPS 代理，维护于 2026-10-18。

说句实在话：公开共享节点随时可能失效，流量也是经过陌生人的服务器。**别拿它登录重要账号。** 有条件的还是用自己的订阅，设置里「用自己的订阅」那一块粘链接就行，稳得多。

配好之后回到源市场，切到需要代理的源，就能看了。

### 第 5 步：效果

切到 Hanime1 之后：

![hanime1 首页](https://i.mji.rip/2026/10/18/1a00f2968316db27fd97f3c98e502b4c.jpeg)

首页、分类、搜索都能用。播不了的编码用播放页右上角那个「内置」按钮切内核。

## 常见问题

**贴了 market.json 提示拉取失败？**  
先换个网络试试（Wi-Fi 和流量切一下）。显示的原因就是真实原因——超时、404、或者响应不是 JSON，照它说的查。清单地址随时可能在变，最新地址看发布页。

**源加进去了，首页一片空白？**  
八成是直连打了个需要代理的站。我的 → 网络代理 → 内置核心 → 免费节点测速并挑选，或者填自己的节点，然后回源市场重新切一次。

**能打开但放不了？**  
播放页右上角点「内置」，切到本地 VLC 软解。HEVC、10bit 这类编码网页内核确实解不动。

**看着看着进度没了？**  
先登录账号（设置 → 账号），片单和历史才会同步。不登录的话只在本机。
