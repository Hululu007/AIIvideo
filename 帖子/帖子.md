# AIIvideo —— 一个自己配源的安卓看片壳子

先说明白这是什么：**AIIvideo 本身不带任何影视内容。** 它是个播放器外壳，内容全部来自你自己填的源——苹果 CMS 接口、动漫站、文件站、KVS 站都行，App 负责识别、抓取、解密、播放。所以你装完第一次打开是空的，必须先给一个源地址才有东西看。

这样做的好处是：源挂了换一个源就行，不用等发新版；坏处是第一次配置得走几步。这个帖子分两半，前半是这次改了什么，后半是照着点一遍就能用的新人指引。

## 一、1.0.26 → 2.0.1：修了什么、加了什么

一句话概括：从「App 内置八家适配器」变成「你自己装源」，源从 8 个变成 12 个。

### 为什么说这是架构级的改动

- **八家的解析搬出了 App。** 八千六百多行 Java（八份站点头 + 九份解析器 + 一张注册表）全部删掉，换成跑在沙箱里的十几份 js —— 行数没省多少，省掉的是「改一个站就要发一次版」。
- **加源、换源、修源都不用发版。** 源是一份 json 加一份 js，贴地址就装；以前改一个选择器要重新打包、签名、发布，再等所有用户更新，现在改完立刻生效。
- **一个源坏了不拖累别的。** 每个源跑在独立进程里，一次能力调用有 90 秒看门狗，源里写出死循环也只失败那一次，不会把界面卡死。
- **源自己发不出任意请求。** 宿主页的 CSP 是 `connect-src 'none'; img-src 'none'`，出站只剩 `net` 一条路，而且主机必须是源自己声明过的；想用 `new Image().src` 把数据带出去也没路。
- **第三方能自己写、自己测。** 接入规范 679 行、样例十份，本地 `node scripts/spider-check.js` 喂 fixture 就能验，不用真机。12 个源能一条条加进来，靠的就是这个。
- **所有源输出同一套模型。** 界面不用为每个站写分支，加一个源前端一行都不用改。

### 加的功能

- **贴一个 https 地址就能加源。** 源现在是一份跑在沙箱里的 js，装完即用，加源不用等发版。
- **源市场 12 个源**：樱花动漫、AGE动漫、影视线路（苹果CMS）、Hanime1、每日大赛、91porn、MissAV、ASMR基佬中心、黄果短剧、Iwara、Pornhub、51吃瓜。
- **新接三个站**：Iwara（二次元创作投稿，播放是两跳签名清单）、Pornhub（四档 HLS）、51吃瓜（境内站，直连最快）。
- **盾后站点能用了。** 整站挂在 Cloudflare 后面的 MissAV 和 Iwara，抓取交给真浏览器内核过盾，源里一句话都不用写。
- **代理跟着源走。** 源可以声明哪个域走代理、其余直连，不再全局一刀切。
- **免费节点 7 条**，点「测速并挑选」自己试延迟最低的那条。

### 修的 bug

- 过盾回填从来没生效过：挑战页被当正文喂给解析器，MissAV 首页直接空白。
- 黄果入口域被判成「走代理」，而配置写的是「全直连」，每次请求 62 秒后超时。
- 换源后内置核心的分流表不重建，切完源必须再换一次节点才恢复。
- 分类页只能翻第一页，第二页以后是空的。
- 点分类进去 0 部作品、全部类型页一片空白。
- 选集点第 3 集，实际请求的还是第 1 集。
- 详情页一直转、不出内容（桥调用没有超时，卡死在那儿）。
- 卡片点开时顿一下再跳。
- 91porn 卡片货不对版（同一批地址返回的顺序会变，校正挪到了服务器）。
- 进度条两端圆弧和拖动圆点不同心。

## 二、新人指引：从装完到能看片

### 第 1 步：第一次打开，先给一个源

装完打开是一片黑，中间弹一个「设置源」面板，就一个输入框要你填地址 —— 因为它真的什么都没有。

在输入框里贴这一行，然后点「获取并应用」：

```
https://149.104.21.177.sslip.io/market-spider.json
```

它是**一份源清单**，不是单个源。贴进去之后 App 不会直接生效，而是把清单里的站点列出来让你挑：

![源清单列表](https://i.mji.rip/2026/10/18/2b12b3274fae3bec9d1e1628a5db74d5.jpeg)

能多选。**第一次先挑 51吃瓜**（境内站，直连最快）**或者影视线路（苹果CMS）**，先跑通一个再说别的。

注意一个坑：**最后一个勾的才是当前生效的源**，前面勾的只是进了源列表，方便以后切。

### 第 2 步：认识设置页

进「我的」→ 右上角设置，长这样：

![设置页](https://i.mji.rip/2026/10/18/a0576613e133412565c0ac7ed37bc000.jpeg)

上往下：内容源（当前用的是哪个）、源市场（点一下换一个源）、网络代理、播放器、外观、账号、版本、片单（历史 / 收藏）、缓存。

大部分东西不用动。需要动的是「网络代理」和「源市场」这两块。

### 第 3 步：源市场随时加源

设置 → 源市场，把刚才那个清单地址填进去：

![源市场填地址](https://i.mji.rip/2026/10/18/dff7a721b5a8aa40afa4efdec0c93059.jpeg)

点「使用这个市场」，出来的是完整清单（现在 12 条）：

![源市场列表](https://i.mji.rip/2026/10/18/f4758b49c6396dba6f3ab7a3c69c3fe2.jpeg)

每个源右边一个「添加并使用时」。点一下就会加进源列表并切过去。上面写着「使用中」的那个就是当前源。

**除了 51吃瓜和影视线路，其余十个基本都要配代理**：樱花动漫、AGE动漫、Hanime1、每日大赛、91porn、MissAV、ASMR基佬中心、黄果短剧、Iwara、Pornhub。直连打不开就先看下一段。

### 第 4 步：配代理（这一步最要命）

不配代理，需代理的那几个源全是空白页或者一直转圈，很多人就在这儿放弃了。

我的 → 网络代理，三档：**直连 / 内置核心 / 外部地址**。

- **直连**：什么都不走，只适合 51吃瓜、影视线路这种。
- **内置核心**：App 自己在本机起一个 SOCKS5。你贴一条 `vmess://`、`vless://`、`trojan://`、`ss://` 分享链接就能用，不需要装任何第三方 App。
- **外部地址**：你手机上有 Clash、v2rayNG 之类的，填它的本地地址（例如 `socks5://127.0.0.1:7890`）。

![代理和免费节点](https://i.mji.rip/2026/10/18/c9203fce02139595f8fdae6642e76181.jpeg)

**没有节点也没有机场的**，直接看「免费节点」那一块，点「测速并挑选」，它会一个个试，挑延迟最低的连上。当前这版内置 7 条实测可用的 HTTPS 代理，维护于 2026-10-18。

说句实在话：公开共享节点随时可能失效，流量也是经过陌生人的服务器。**别拿它登录重要账号。** 有条件的还是用自己的订阅，设置里「用自己的订阅」那一块粘链接就行，稳得多。

配好之后回到源市场，切到需要代理的源，就能看了。

### 第 5 步：效果

切到 Hanime1 之后：

![hanime1 首页](https://i.mji.rip/2026/10/18/1a00f2968316db27fd97f3c98e502b4c.jpeg)

首页、分类、搜索都能用。播不了的编码用播放页右上角那个「内置」按钮切内核。

## 常见问题

**贴了清单地址提示拉取失败？**  
先换个网络试试（Wi-Fi 和流量切一下）。显示的原因就是真实原因——超时、404、或者响应不是 JSON，照它说的查。清单地址随时可能在变，最新地址看发布页。

**源加进去了，首页一片空白？**  
八成是直连打了个需要代理的站。我的 → 网络代理 → 内置核心 → 免费节点测速并挑选，或者填自己的节点，然后回源市场重新切一次。

**能打开但放不了？**  
播放页右上角点「内置」，切到本地 VLC 软解。HEVC、10bit 这类编码网页内核确实解不动。

**切了源之后一直转圈，换个节点又好了？**  
旧版有这个毛病，2.0.1 修了：换源会连带重建内置核心的分流表，不再需要手动换节点。

**看着看着进度没了？**  
先登录账号（设置 → 账号），片单和历史才会同步。不登录的话只在本机。
